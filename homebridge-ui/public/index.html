The air conditioner does not hand out a token on request — it calls back to this machine the moment it powers on. So the order matters:

  1. Power the air conditioner off (remote or plug).
  2. Press Start pairing below.
  3. When asked, power it back on.

If Homebridge runs in a container without host networking, the callback cannot reach it. Run npx homebridge-samsung-rac-probe pair --host <ip> on the host instead and paste the token below.
